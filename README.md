✨ The Lost Light of Diwali

[🎮 Watch the Demo →](https://drive.google.com/file/d/1PhOTb29NnRySSEU64sXctvLoy5o-d2-G/view?usp=sharing)

A magical interactive storybook adventure inspired by the festival of Diwali. Help a little elephant restore the light to a sleepy village and bring joy back to the celebration.

Story

The festival is fading. The village is dim, the lanterns are dark, and the spirit of Diwali has gone missing.

With courage, curiosity, and a little help from a friendly elephant, the journey begins to bring light back to the streets, homes, and hearts of the village.

The game combines storytelling, level-based gameplay, and festive visuals to create an interactive celebration of Diwali.

Features

* Interactive Diwali-themed story experience
* Guided narrative progression with cinematic scenes
* Puzzle-style gameplay across multiple levels
* Light and lantern restoration mechanics
* Animated village environment
* Ambient sound and music
* Responsive UI

Built With

* React
* TypeScript
* Vite
* Tailwind CSS
* TanStack Start
* Cloudfare
